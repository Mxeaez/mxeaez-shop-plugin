# Mxeaez Shop Plugin

This plugin is to be used with the [Mxeaez Shop](https://www.twitch.tv/mxeaez) Twitch extension to add fun redeems to the game.

## Requirements

- [RuneLite](https://runelite.net/) client
- The Mxeaez Shop Twitch extension installed on the channel

## Setup

1. Install the plugin via the RuneLite Plugin Hub
2. In the plugin settings, enter the server URL and API key provided by the streamer
3. Redeem effects in the Twitch channel panel — they will trigger live in-game

## Effects

| Effect | Description | Duration |
|---|---|---|
| NPC Rename | Renames a targeted NPC | Permanent |
| Lost Boss | Spawns a random OSRS boss that wanders nearby | 60s |
| Item Swap | Swaps the visual of an equipped item | 60s |
| Squeaky Weapon | Replaces attack sounds with a squeaky toy | 10s |
| Outfit Swap | Replaces the visual of your worn outfit | 60s |
